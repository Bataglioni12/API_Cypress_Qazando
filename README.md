# Testes de API com Cypress - Curso QAzando

Este repositório contém os testes de API automatizados que foram criados durante o curso **Automação de Testes com Cypress** oferecido pela **QAzando**. O objetivo deste repositório é demonstrar a aplicação prática do **Cypress** para automação de testes em APIs.

## Tecnologias Utilizadas

- **Cypress**: Framework de testes para JavaScript, utilizado para automação de testes de APIs.
- **JavaScript**: Linguagem de programação utilizada para escrever os testes.
- **Node.js**: Ambiente de execução para JavaScript.
- **NPM**: Gerenciador de pacotes utilizado para instalação das dependências do projeto.

## Estrutura do Projeto

- `cypress/`: Contém os arquivos de teste.
  - `integration/`: Pasta onde estão localizados os testes de API.
  - `support/`: Contém arquivos de configuração e comandos customizados.
- `package.json`: Gerenciador de pacotes com as dependências do projeto.
- `cypress.json`: Arquivo de configuração do Cypress.
